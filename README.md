# Restaurant Website

A responsive 4-page restaurant website built with React, React Router and CSS. Frontend only.

**Live demo:** https://keshavmishrasde.github.io/restaurant-website-react/


## Pages
- Menu
- Story
- Gathering
- Contact

## Tech Stack
- React
- React Router
- CSS
- Vite

## Features
- only for desktop
- Multi-page navigation with React Router
- Reusable components

## Run Locally
```bash
git clone https://github.com/keshavmishrasde/restaurant-website-react.git
cd restaurant-website-react
npm install
npm run dev
```

## Note
This is a frontend-only project. No backend or database.
